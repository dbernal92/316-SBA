# To-Do List App

A simple and interactive **To-Do List** application that allows users to add, edit, and delete tasks. The app includes **local storage** support, **dark mode**, and additional features such as task counters and timestamps.

---

## Features

- Add tasks to the list
- Edit tasks by clicking on them
- Delete individual tasks
- Save tasks in **localStorage** (tasks persist after page refresh)
- Dark mode toggle
- Task counter to track remaining tasks
- Clear all tasks button
- Timestamps for when tasks were added

---

## How to Use

### Add a Task
1. Type a task into the input field.
2. Click the **Add Task** button.
3. The task will appear in the list below.

### Edit a Task
1. Click on a task to edit it.
2. Press **Enter** or click outside the input field to save changes.

### Delete a Task
- Click the **"-"** button next to a task to remove it from the list.

### Clear All Tasks
- Click the **Clear All** button to remove all tasks at once.

### Dark Mode
- Click the **Toggle Dark Mode** button at the top to switch between light and dark themes.
